# ПроектРасчёт

Локальный калькулятор стоимости проектных работ с двумя режимами:

**Онлайн-версия:** <https://ntrworkspace.github.io/proektraschet-calculator/>

- **Нормативный** — исправляет границы интервалов, профиль разделов, НДС 22%, сокращение срока и ограничение произведения коэффициентов значением 2,0.
- **Совместимость** — воспроизводит обнаруженную логику калькулятора pbrassvet.ru для сопоставления результатов, включая известные особенности.

В калькулятор загружены 16 категорий, 248 видимых типов объектов, 1 317 достижимых интервалов, профили разделов, сроки и 132 коэффициента объёма НТС.

Коэффициент пересчёта `KP` выбирается автоматически по московской дате из
квартальной таблицы индексов проектных работ к ценам на 01.01.2001. Раз в неделю
GitHub Actions проверяет [публикацию КонсультантПлюс](https://www.consultant.ru/document/cons_doc_LAW_39473/)
и добавляет новые кварталы; опубликованное заранее значение начинает действовать
с первого дня соответствующего квартала. Ручной ввод остаётся доступен.

> Репозиторий содержит расчётную модель и справочные данные для исследования и
> проверки. Перед коммерческим применением ознакомьтесь с [NOTICE.md](NOTICE.md).

## Запуск

Требуются Node.js 22+ и pnpm.

```bash
pnpm install
pnpm dev
```

Откройте `http://localhost:3000`.

## Проверка

```bash
pnpm test
pnpm exec tsc --noEmit
pnpm exec eslint app tests --ignore-pattern app/data/calculator-data.json
```

## Статус нормативности

Исправленный режим является проверяемой инженерной реализацией на нормализованных данных аудита. Перед использованием в договорной цене необходима построчная сверка таблиц с официальной редакцией МРР и утверждение принятых трактовок ответственным специалистом. Код и интерфейс выполнены самостоятельно; режим совместимости предназначен для контрольного сравнения.
